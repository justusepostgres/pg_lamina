# justusepostgres identity

The **One Query** mark reduces the organization name to a direct developer cue: `1;` — one decisive SQL statement.

## Primary color

- Signal Coral: `#F04F47`
- RGB: `240, 79, 71`
- Approximate CMYK: `0, 67, 70, 6`
- White: `#FFFFFF`
- Ink: `#11161F`

## Files

- `justusepostgres-avatar.svg` and `.png`: full-bleed GitHub organization avatar.
- `justusepostgres-symbol.svg`: transparent Signal Coral symbol.
- `justusepostgres-symbol-black.svg`: one-color version for light backgrounds.
- `justusepostgres-symbol-white.svg`: reversed version for dark backgrounds.

## Usage

- Keep clear space around the standalone symbol equal to the semicolon dot diameter.
- Use the full-bleed avatar for GitHub and other masked profile images.
- Do not recolor individual parts, add effects, stretch, rotate, or place the coral symbol on low-contrast red or orange backgrounds.
- Minimum recommended size: 16 px for the avatar; 24 px for the transparent symbol.

The letterforms are custom vector paths and do not require a font license. Pantone matching should be verified against a physical guide before print production.
